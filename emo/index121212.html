Robot EMO — Buku Tamu, Chat, Cuaca, Jadwal & Quiz

Widget melayang di pojok kanan bawah halaman ini. Klik badan robotnya untuk mulai, atau coba tombol 💬 Chat, 🕌 Solat, 🎵 Lagu, ⛅ Cuaca, 📅 Jadwal, 🧠 Quiz, dan ℹ️ About di balon percakapannya. Pst... ketik #joke, #quiz, atau #dance di kolom chat 😉

FITUR

  1. Buku tamu + pilihan tujuan — Buku Tamu / Kritik & Saran / Kirim Atesi / Curhat / Lainnya — tersimpan otomatis ke Google Spreadsheet (Apps Script).
  2. Lagu & sapaan otomatis — dari sheet Lirik; saat audio diputar EMO menyanyi + equalizer di atas kepalanya.
  3. Bot chat — dari sheet Chat (pertanyaan, opsi jawaban pertama, jawaban ke 2, jawaban ke 3, kategori).
  4. Tiket antrean #ticket — by name & kelas (Siswa/Guru/Umum), nomor antrean otomatis ke sheet Ticket (aktif dari sheet Konfig).
  5. Cuaca otomatis ⛅ — suhu + prakiraan 3 hari (Open-Meteo, gratis tanpa API key) + saran bawa payung; sapaan pembuka menyertakan cuaca kota.
  6. Jadwal pelajaran 📅 — dari sheet Jadwal; tampil otomatis per hari ini, bisa lihat hari lain & filter kelas.
  7. Quiz interaktif 🧠 — dari sheet Quiz; soal diacak, poin, skor akhir, predikat & rekor pribadi.
  8. Pengingat waktu solat — jadwal otomatis via API Aladhan (metode Kemenag RI), bisa ganti kota.
  9. Karakter hidup — efek ketik, sapaan pagi/siang/sore/malam, mode begadang, efek suara blip (🔊 on/off), dan easter egg #dance #party #joke #love #spin.
