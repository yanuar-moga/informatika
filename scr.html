Script Video UKIN Informatika

Materi: Perangkat Lunak (Software)

Gesture: Guru berdiri di depan kelas, tersenyum, kontak mata dengan siswa. Guru: Assalamu’alaikum warahmatullahi wabarakatuh. Selamat pagi anak-anak. Siswa: Waalaikumsalam warahmatullahi wabarakatuh. Guru: Bagaimana kabar kalian hari ini? Siswa: Baik Pak. Guru: Alhamdulillah, semoga semuanya sehat dan siap mengikuti pembelajaran hari ini.
Gesture: Guru menundukkan kepala. Guru: Sebelum kita memulai pembelajaran, mari kita berdoa agar kegiatan belajar kita berjalan dengan lancar.
Gesture: Guru membuka daftar hadir pada tablet. Guru: Bapak akan mengecek kehadiran kalian terlebih dahulu. (Guru menyebut beberapa nama siswa) Catatan: Tablet menunjukkan pemanfaatan teknologi dalam manajemen kelas.
Guru: Pada pertemuan sebelumnya kita telah mempelajari sistem komputer. Masih ingat terdiri dari apa saja? Siswa: Hardware, Software, Brainware. Guru: Bagus sekali. Hari ini kita akan mempelajari salah satu komponen tersebut yaitu perangkat lunak atau software.
Guru: Siapa di sini yang setiap hari menggunakan HP? (Siswa mengangkat tangan) Guru: Aplikasi apa saja yang sering kalian gunakan? Siswa: WhatsApp, Instagram, Game, Chrome. Guru: Semua aplikasi tersebut sebenarnya termasuk software.
Hari ini kita akan mempelajari tentang perangkat lunak atau software. Tujuan pembelajaran: 1. Memahami pengertian software 2. Mengenali jenis-jenis software 3. Menganalisis fungsi software dalam kehidupan sehari-hari Kegiatan pembelajaran: - Mengamati contoh software - Diskusi kelompok - Presentasi hasil diskusi
Guru menampilkan gambar: Windows Android Microsoft Word Chrome Instagram Guru: Perhatikan gambar software berikut.
Guru: Apakah semua software ini memiliki fungsi yang sama? Siswa: Tidak. Guru: Apa perbedaannya? Siswa: Windows untuk menjalankan komputer, Word untuk mengetik.
Tugas Kelompok: 1. Mengelompokkan software 2. Menentukan mana sistem operasi 3. Menentukan mana aplikasi 4. Menjawab pertanyaan: Apa yang terjadi jika komputer tidak memiliki sistem operasi? Diskusikan bersama kelompok kalian.
Guru: Kelompok pertama silakan mempresentasikan hasil diskusinya. Siswa: Sistem Operasi: Windows, Android, Linux Aplikasi: Word, Chrome, Instagram Guru: Bagus sekali.
Software adalah program yang digunakan untuk menjalankan komputer dan membantu pengguna melakukan berbagai pekerjaan. Jenis software: 1. Sistem Operasi Contoh: Windows Linux Android iOS 2. Aplikasi Contoh: Microsoft Word Excel Google Chrome Instagram
Guru: Apa manfaat software dalam kehidupan sehari-hari? Siswa: Membantu belajar Mengetik tugas Mencari informasi
Kesimpulan: - Software membantu komputer bekerja - Software terdiri dari sistem operasi dan aplikasi - Software membantu manusia dalam kehidupan sehari-hari
Guru: Terima kasih atas partisipasi kalian. Tetap gunakan teknologi secara bijak dan bertanggung jawab. Wassalamu’alaikum warahmatullahi wabarakatuh.
